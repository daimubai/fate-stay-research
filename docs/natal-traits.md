# 十二长生与七项神煞

排盘接口沿用固定北京时间、立春换年、节令换月、23 点换日。此功能针对出生四柱；大运、流年、流月、流日、流时的属性保持现有口径。

## 十二长生

`pillarDetails[].terrain` 为出生日干对该柱地支的十二长生，`selfTerrain` 为该柱自身天干对自身地支的自坐长生。两者均直接调用 Tyme4j 1.5.2 `HeavenStem.getTerrain(EarthBranch)`，阳干顺行、阴干逆行，戊随丙、己随丁，不引入旺衰评分。

样例 1986-05-29 13:37：丙寅、癸巳、癸酉、己未。日干癸对四支依次为沐浴、胎、病、墓；自坐依次为长生、胎、病、冠带。

## 神煞规则边界

Tyme4j 的 `God` 为黄历吉神凶神，不能直接作为八字四柱神煞。本项目在 Tyme4j 四柱之上增加独立、可测试的七项规则，响应 `shenSha.provider = PROJECT_RULES_ON_TYME4J`、`ruleVersion = common-seven-day-year-v1`。未命中表示未命中这七项规则，不表示没有其他流派神煞。

| 名称 | 参照与目标 |
| --- | --- |
| 天乙贵人 | 仅日干：甲戊庚→丑未，乙己→子申，丙丁→亥酉，辛→寅午，壬癸→卯巳 |
| 禄神 | 日干十二长生的临官地支，取自 Tyme4j |
| 驿马 | 年支和日支分别查四支，见下表 |
| 桃花（咸池） | 年支和日支分别查四支，见下表 |
| 华盖 | 年支和日支分别查四支，见下表 |
| 将星 | 年支和日支分别查四支，见下表 |
| 旬空 | 日柱 `SixtyCycle.getExtraEarthBranches()` 的两支，查四柱地支 |

| 参照支所属三合组 | 驿马 | 桃花 | 华盖 | 将星 |
| --- | --- | --- | --- | --- |
| 申子辰 | 寅 | 酉 | 辰 | 子 |
| 寅午戌 | 申 | 卯 | 戌 | 午 |
| 亥卯未 | 巳 | 子 | 未 | 卯 |
| 巳酉丑 | 亥 | 午 | 丑 | 酉 |

每项都检查四柱地支，包括参照柱自身。同柱同项只生成一条 `hit`；年支与日支同时命中时，保留两条 `bases`。不根据性别更改出生神煞。天乙等存在流派差异，此版本固定上述查表，不混合年干查法或其他庚干贵人口径。

`shenSha.rules` 列出全部启用规则；`hits` 每项包含 `id/name/pillarKey/pillarLabel/targetBranch`，`bases` 包含 `reference/sourceValue/targetValues`，便于追溯命中依据。样例命中月柱天乙贵人（日干癸查卯巳）和日柱将星（日支酉查酉）。空结果为 `hits: []`。

PC 和手机均保留四柱横向对照，长生神煞默认折叠，展开后可查看对照表、命中依据和规则版本。信息只作传统分类，不单独作吉凶判断。

## 本机缓存

旧快照可正常读取，缺少新字段时提示重新排盘。重新计算同一出生时间、性别时更新原位置，保留名称，不增加缓存槽位。新快照连同长生和神煞依据一起缓存；有新字段但结构损坏的快照会被跳过。仍最多保存三份，流月/日/时仍为按需内存缓存。
