# 紧凑排盘工作台

## 默认显示

- PC：左侧出生信息与本机记录，右侧四柱命盘和紧凑运程导航；取消大面积介绍区和整屏服务诊断。
- 手机：已有命盘时收起出生信息与记录列表，四柱仍横向对照；“修改出生信息”“切换 / 管理”按需展开。
- 默认命盘展示天干十神、干支、藏干和纳音。合冲刑破害、十二长生/神煞、胎元/命宫/身宫、五行解释、计算口径都可展开。藏干完整五行与气序在说明中保留。
- 运程只展示所选大运、流年和单份当前详情。起运精确时刻保留单行摘要，间隔、年龄和交运说明收起。

## 时间选择

五个入口为大运、流年、流月、流日、流时。桌面打开居中弹窗，手机打开底部面板。选项有干支与必要说明，选中后自动关闭；Esc、关闭按钮和点击遮罩可取消，焦点回到入口。弹窗显示期间锁定背景滚动。

| 操作 | 请求与状态 |
| --- | --- |
| 打开命盘 | 不请求流月、流日、流时 |
| 切换大运 | 更新该运内的流年，重置下级时间 |
| 切换流年 | 重置流月、流日和流时，不自动请求下级 |
| 打开流月选择器 | 请求所选流年的十二节令月 |
| 选定流月 | 展示该月，启用流日入口，不请求流日 |
| 打开流日选择器 | 请求所选节令月的流日 |
| 选定流日 | 展示该日，启用流时入口，不请求流时 |
| 打开流时选择器 | 请求所选流日的十二时辰 |
| 选择流时 | 展示该时辰的十神、五行、纳音；起止与节令截断信息可展开 |

每个时间层级独立重试、独立版本守卫；父级变化时取消下级请求，旧响应不会覆盖新上下文。月、日、时各缓存最多 24 份响应，缓存键包含出生时刻和全部必要上级时间；不写入 localStorage。关闭弹窗不会清除已加载内容，再次打开可复用。

已选路径可点击回看年/月/日/时详情。子时前日 23 点起、流月跨公历年、流日节令截断，以及区间外参考时辰等计算信息均保留，默认收进“查看精确起止与历法说明”。未选择父级时禁用下级入口。

## 参考与实现

参考 [青囊公开八字页](https://www.qingnang.cc/bazi) 的排盘/明细/多视角分层和高级选项、[八字集](https://baziji.com/) 的输入/设置分层，结合本项目已有配色和数据范围设计工作台。参考页面的公开文案可访问；未登录的实际结果页未作为像素级复刻目标，不引入它们的登录、收费、地点或历法校正功能。

界面布局概念由设计图先行，实际年月、起运、宫位和五行均取本项目接口，不使用设计图中的示意数值。新增 `TimeSelect.vue` 和 `use-flow-selection.ts`，统一旧的流月/日/时组件；无新增依赖，无后端计算或 API 语义改动。

四柱关系摘要默认折叠；展开后按类型筛选、查看参与柱位及依据，点击一项标记命盘对应天干或地支。取消选择、切换类别或收起面板会清除标记，手机可点击返回已标记柱位。规则与形态见 [四柱关系设计](pillar-relations.md)。
